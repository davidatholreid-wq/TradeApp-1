## 💡 Pro tips

1. **Cut on the beat** — TradeAPP is a fast, confident brand. Sync screen cuts to the music.
2. **Ken-burns on stills** — a subtle 3-5% zoom over 2-4 seconds makes each screenshot feel alive.
3. **Layer sound design** — a soft "swoosh" as tiles fan in, a subtle "chime" when the offer amount lands, a warm "pop" when the timeline opens.
4. **Reserve the last 3 seconds** for the wordmark + URL. Never talk over the URL — let it breathe.
